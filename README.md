ربات پیشرفته و سرورلس تلگرام مبتنی بر پلتفرم **tgcloud** برای جستجو، استریم، دریافت و مرور هوشمند **۳۱۴ اپیزود پادکست و بیش از ۶,۸۰۰ قطعه موسیقی باکیفیت** با تفکیک مودها و سبک‌ها.

---

## ✨ قابلیت‌ها و ویژگی‌های کلیدی

1. **آرشیو کامل ۳۱۴ اپیزود پادکست پلی‌لیست:**
   - دسته‌بندی و شماره‌گذاری دقیق همراه با نام‌های اصلاح‌شده اپیزودها
   - لینک مستقیم به هر قسمت در Castbox و کانال تلگرام
   - صفحه‌بندی هوشمند دقیقاً ۱۰ اپیزود در هر صفحه (۳۲ صفحه) با جابجایی فوق‌العاده سریع

2. **دسترسی به ۶,۸۶۹ قطعه موسیقی باکیفیت:**
   - نمایش لیست قطعات هر اپیزود با عنوان، خواننده، زمان و حجم فایل
   - امکان دریافت تکی آهنگ‌ها یا ارسال یکجای قطعات هر اپیزود

3. **سیستم تگ‌بندی و پیشنهاد مود (Moods & Tags):**
   - تفکیک قطعات در ۸ سبک اختصاصی:
     - 🎸 **بیکلام و سازی** (گیتار، پیانو، ویولن...)
     - 🧘 **آرامش‌بخش و ملو** (کافه، خواب، شبانه، باران...)
     - 🍂 **غمگین و دلتنگی** (پاییز، خزان، حسرت، تنهایی...)
     - 🕺 **شاد و پرانرژی** (ریتمیک، دنس، هاوس، مهمانی...)
     - 🚗 **جاده‌ای و سفر** (ماشین، رانندگی، سفر...)
     - 🎷 **جاز و بلوز** (ساکسفون، بلوز، جاز...)
     - 📻 **نوستالژی و اصیل ایرانی** (شجریان، فروغی، هایده...)
     - 🌍 **آهنگ‌های خارجی و ملل** (فرانسوی، اسپانیایی، راک، پاپ، ترکی...)
   - کلید دریافت ۵ قطعه تصادفی از هر مود با یک لمس

4. **سیستم کش خودکار فایل‌ها (File_ID Auto-Caching):**
   - معماری هیبریدی: اگر فایل در دیتابیس ثبت شده باشد (`file_id`) مستقیماً فایل اصلی با تگ و کپشن اختصاصی کانال **@MyLeitner** ارسال می‌شود.
   - فوروارد مستقیم هر آهنگ از کانال به ربات، شناسه فایل تلگرام را ثبت و کش دائمی می‌کند.

5. **منوی چت‌باکس ثابت (Persistent Reply Keyboard):**
   - دکمه‌های بزرگ و دائمی در نوار پیام‌رسان تلگرام (کنار کادر تایپ):
     - `🎲 آهنگ تصادفی فوری ⚡`
     - `🏷️ مودها و سبک‌ها 🎧`
     - `🎙️ لیست پادکست‌ها`
     - `🔍 جستجوی آهنگ`
     - `🌟 ۱۰ اپیزود اخیر`
     - `📢 کانال @MyLeitner`
     - `👨‍💻 درباره توسعه‌دهنده`
     - `🎛️ منوی شیشه‌ای کامل`

6. **پشتیبانی کامل از اینلاین (Inline Query Mode):**
   - با تایپ `@Playlist_podcast_bot` در هر گروه یا چتی، پنل جستجو و انتخاب تصادفی آهنگ‌ها بدون نیاز به عضویت ربات در گروه باز می‌شود.

## 🚀 راهنمای نصب، راه‌اندازی و دیپلوی

### ۱. پیش‌نیازها
* Node.js نسخه ۱۸ یا بالاتر
* حساب کاربری فعال در پلتفرم [tgcloud](https://tgcloud.io)
* توکن ربات تلگرام از [BotFather](https://t.me/BotFather)

### ۲. کلون کردن ریپازیتوری و نصب وابستگی‌ها
```bash
git clone https://github.com/mohsen-niksirat/Playlist_podcast_bot.git
cd Playlist_podcast_bot
npm install
```

### ۳. اتصال به tgcloud و لاگین
```bash
# وارد کردن توکن دسترسی بات
npx tgcloud login
```

### ۴. ساخت پایگاه داده و مهاجرت جداول
```bash
npx tgcloud push
npx tgcloud migrate --safe
```

### ۵. بررسی وضعیت استقرار و وب‌هوک
```bash
npx tgcloud webhook
```

## ⚙️ تنظیمات بات‌فادر (BotFather Settings)

برای بهترین تجربه کاربری، دستورات و تنظیمات زیر را در **@BotFather** اعمال کنید:

### ۱. تنظیم دستورات (`/setcommands`):
```text
start - 🏠 منوی اصلی ربات
episodes - 🎧 لیست کامل اپیزودها
tags - 🏷️ انتخاب آهنگ بر اساس مود و سبک
search - 🔍 جستجوی آهنگ، خواننده یا پادکست
random - 🎲 اپیزود تصادفی پیشنهادی
latest - 🌟 ۱۰ اپیزود اخیر
panel - 🎛️ پنل کنترل اینلاین
about - 📻 درباره سازنده و کست‌باکس
dev - 👨‍💻 درباره توسعه‌دهنده
stats - 📊 آمار ربات (مخصوص ادمین)
```

### ۲. فعال‌سازی حالت اینلاین (`/setinline`):
دستور `/setinline` را بفرستید، ربات را انتخاب کنید و متن زیر را به عنوان Placeholder ارسال کنید:
`جستجوی آهنگ یا پادکست...`
